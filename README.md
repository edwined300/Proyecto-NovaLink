# Proyecto-NovaLink

Descripción General del Proyecto – Nova Link

Nova Link es una empresa orientada a la conectividad y servicios tecnológicos, diseñada para operar de manera eficiente en múltiples sedes geográficas. Este proyecto representa la infraestructura de red corporativa de la empresa, enfocada en la interconexión segura, la alta disponibilidad y la gestión centralizada de los recursos de red.

La red de Nova Link conecta sus sedes principales ubicadas en Santiago, Santo Domingo y La Romana, permitiendo una comunicación confiable entre ellas y acceso controlado a servicios internos y externos. La arquitectura fue diseñada siguiendo buenas prácticas de redes empresariales, priorizando la seguridad, la escalabilidad y el orden lógico de la infraestructura.

El proyecto sirve como un laboratorio académico y práctico, ideal para demostrar conocimientos en redes, enrutamiento, VPNs, segmentación de red y administración de infraestructuras empresariales, alineado con los contenidos de CCNA y networking profesional.
